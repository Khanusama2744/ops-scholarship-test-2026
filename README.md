# Oxford School & College Sundovi — Scholarship Test Result 2026

A lightweight static result website built with HTML5, CSS3, vanilla JavaScript, JSON and a Python conversion tool. No backend, database or framework is required.

## 1. Project structure

├── classes.html                Class-wise result tables (Classes 3rd to 9th)

├── js/
│   └── app.js                  Search, ranking display, tables, lightbox, sharing
├── data/

├── assets/

│   └── images/

│       ├── school-building.webp
│       ├── gallery-1.webp

`Result_with_Pass_Fail.xlsx` is generated by `convert.py` in the project root. It is private, office-only, ignored by Git and excluded from Vercel. The original source workbook is never overwritten.

## 2. How to run `convert.py`

Requirements: Python 3.9+ and `openpyxl` (`pip install openpyxl`).

Place the original `.xlsx` workbook in the project folder, then run:

```bash
python tools/convert.py
```

Or pass an explicit path:

```bash
python tools/convert.py "path/to/Oxford_School_All_Students_Marks_Entry_Sheet-v3.xlsx"
```

The script:

- reads `All Students Marks Sheet` and cross-checks `Top 3 Achievers`;
- cleans whitespace and normalises classes, roll numbers and marks;
- calculates percentages, class-wise positions and overall positions using competition ranking (ties share a position; absent students are excluded from rankings);
- calculates scholarships from class position only;
- flags tied top-three positions and any top-three holder below the passing mark for management review;
- writes `data/results.json` and the private `Result_with_Pass_Fail.xlsx`;
- prints a full terminal report with ties, cleaning changes and statistics.

Run `python tools/prepare_assets.py` if you need to regenerate the optimised images from the supplied originals (requires `Pillow`).

## 3. How to change `PASSING_MARKS`

Open `tools/convert.py` and edit this line near the top:

```python
PASSING_MARKS = 29
```

Then re-run `python tools/convert.py`. Every status, statistic and scholarship review case is recalculated automatically.

Other configuration near the top of the file:

- `PUBLISH_FATHER_NAME` and `PUBLISH_SCHOOL_NAME` — set to `False` if the school withdraws publication authorisation.
- `DEFAULT_TOTAL_MARKS` — used when the workbook has no maximum-marks cell.

## 4. Test locally

Because the site uses `fetch()`, it must be served over HTTP (opening `index.html` directly with `file://` will not load the JSON).

```bash
cd oxford-scholarship-result-2026
python -m http.server 8000
```

Then open <http://localhost:8000>.

## 5. Push to GitHub

```bash
git init
git add .
git commit -m "Initial scholarship result website"
git remote add origin https://github.com/Khanusama2744/ops-scholarship-test-2026.git
git push -u origin master
```

Never commit the original workbook, `Result_with_Pass_Fail.xlsx`, contact lists or any other private file. The `.gitignore` file already excludes them — double-check with `git status` before committing.

## 6. Deploy on Vercel

1. Open Vercel and select **Add New Project**.
2. Import the GitHub repository.
3. Framework Preset: **Other**.
4. Build Command: leave empty.
5. Output Directory: root (`.`).
6. Deploy.

`.vercelignore` prevents private source files from being uploaded. Only `index.html`, `classes.html`, `404.html`, `css/`, `js/`, `data/results.json`, `assets/` and `vercel.json` are needed by the live site.

## 7. Update results later

1. Replace the source workbook with the revised one (or place it in `private/`).
2. Update `PASSING_MARKS` if required.
3. Run `python tools/convert.py` and review the terminal report, especially management review cases.
4. Check the new `data/results.json` and the private workbook.
5. Commit only the public files and push to GitHub. Vercel redeploys automatically.

## 8. Add a custom domain

In Vercel: **Project → Settings → Domains → Add**, enter your domain, then add the DNS records shown by Vercel at your domain registrar. After DNS verification, set the domain as Production. Update `og:url` / `og:image` in both HTML files to the final absolute URLs so WhatsApp and social previews use the correct address.

## Privacy notes

`data/results.json` is publicly downloadable. It contains only roll number, name, father/guardian name, class, previous school, marks, percentage, positions, status and scholarship. Contact numbers, transaction IDs, registration details and the original/updated Excel files are never published.

All gallery images were supplied for this project. The About text and motto were supplied by the school office.
